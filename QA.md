# Release checks

- [ ] Run `make build`, `make verify` and `make test`; the tests compare publication output, check imposition and decode the rendered programme and stream QR codes.
- [ ] Confirm that the live programme and printed schedule agree, especially 31 October at 14:45; see `PROVENANCE.md`.
- [ ] Check programme translations, speaker names and inferred durations.
- [ ] Test both language views and Skedz links on the published site, including cross-origin XML access.

A physical proof is optional. If printing one, use A4 landscape at 100% scale and short-edge duplex without additional booklet mode.

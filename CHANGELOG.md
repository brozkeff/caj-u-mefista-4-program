# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [4.1.0] - 2026-10-28

### Changed

- Simplified the publication scripts and moved conference and booklet presentation details into editable data files.
- Added regression checks for the reviewed v4.0.4 schedules and booklet content, permanent XML structure checks, and automated QR decoding from the PDFs.
- Made physical print proofs optional in the release guidance.
- Centralized publication filenames and stable event identifiers.

## [4.0.4] - 2026-10-27

### Changed

- Updated the Czech and English logos in the booklets and website.
- Linked the official conference programmes from the website and the interactive programme from this README.

## [4.0.3] - 2026-10-27

### Added

- Bilingual online stream page with a channel QR code.
- Untimed exhibitions in the website and XML as untimed schedule extensions.

### Changed

- Simplified the cover and corrected exhibition artists and titles.

## [4.0.2] - 2026-10-27

### Changed

- Programme QR codes and printed links now open the interactive online schedule.

## [4.0.1] - 2026-10-27

### Changed

- Updated GitHub Pages deployment and artifact upload to Node.js 24 actions.

## [4.0.0] - 2026-10-27

### Added

- Reviewed bilingual abstracts, a canonical timetable and source provenance.
- Czech and English A5 booklets, a reversible reader, an imposed A4 duplex master, and programme QR codes.
- Bilingual Pentabarf schedules and a static schedule website with Prague times, Giggity and Skedz links.
- Local build and verification tools, GitHub Pages workflow, release packaging, and EUPL-1.2 software license.

### Historical context

- Online cloud iterations V1–V3 explored text, layout and workbook-driven generation before the reviewed sources were established; they are not production releases.

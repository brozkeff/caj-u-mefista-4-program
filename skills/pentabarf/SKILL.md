# Pentabarf schedules

Edit `data/program.json` as the canonical timetable and retain published event IDs. A lecture requires a reviewed workbook abstract. Untimed events are omitted from Pentabarf; unspecified durations are estimates and can be overridden with `duration_minutes`. `make xml` regenerates both language schedules and the website. Confirm the hosted XML is public and test the mobile links after publishing.

# A5 typesetting and duplex assembly

Build with XeLaTeX using `tex/layout.tex` and generated TeX. Escape user text, keep lecture headings with their opening text, and preserve continuous flow, Unicode, vector QR codes and a one-page programme per language. Use Noto Serif/Display without redistributing fonts. Inspect the A5 PDFs and a folded short-edge-duplex A4 proof before printing; do not enable booklet mode in the printer driver.

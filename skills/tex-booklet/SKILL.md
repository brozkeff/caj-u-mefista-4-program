# A5 typesetting and duplex assembly

Build with XeLaTeX using `tex/layout.tex` and generated TeX. Escape user text, keep lecture headings with their opening text, and preserve continuous flow, Unicode, vector QR codes and a one-page programme per language. Use Noto Serif/Display without redistributing fonts. Run publication regression and rendered QR decoding tests; a folded short-edge-duplex A4 proof is optional. Do not enable booklet mode in the printer driver.
